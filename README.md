# Snake Game
Snake game creation for AP Computer Science Principles

Snake Game was created using the Javascript library, P5.js. 


This game was created by me during my junior year of high school for AP CSP. The game isn't fully functional, but as my first CS creation for showcase, it is a memorable project in its own right. Special shoutout to my computer science principles teacher, Emily Fields, for assisting in the implementation of some of the game features.
